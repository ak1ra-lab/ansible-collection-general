Contributing
============

Development setup, the test matrix, and the Molecule workflow are documented
in the repository's `CONTRIBUTING.md
<https://github.com/ak1ra-lab/ansible-collection-general/blob/master/CONTRIBUTING.md>`_.

Common commands
---------------

.. code-block:: shell

   uv sync --group dev
   just lint          # ruff
   just typecheck     # mypy against the installed collection namespace
   just unit-test     # tox-ansible unit environment
   just ansible-lint
   just changelog-lint # antsibull-changelog fragment lint
   just docs-lint     # antsibull-docs lint-collection-docs
   just docs-build    # regenerate reference pages and build Sphinx

Documentation sources
---------------------

- Role argument specs live in ``roles/<role>/meta/argument_specs.yml`` and
  generate the canonical variable reference; role READMEs keep purpose,
  deployed artifacts, and examples.
- Role reference pages are generated by ``antsibull-docs`` from the argument
  specs. Do not edit the generated ``*_role.rst`` pages by hand.
- Plugin reference pages are generated from the ``DOCUMENTATION``,
  ``EXAMPLES``, and ``RETURN`` blocks in ``plugins/``.
- Hand-written guides live under ``docs/docsite/rst/``.

Docs changes must pass ``just docs-lint`` and ``just docs-build``.
